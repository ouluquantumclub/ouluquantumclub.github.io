# Oulu Quantum Club website

This repository contains the public website for **Oulu Quantum Club**.

## GitHub Pages

For the organization repository named:

`ouluquantumclub.github.io`

GitHub Pages can publish the site at:

`https://ouluquantumclub.github.io`

### Publish

1. Upload all files and the `assets` folder to the repository root.
2. Open **Settings → Pages**.
3. Under **Build and deployment**, choose **Deploy from a branch**.
4. Select **main** and **/ (root)**.
5. Save.

## Files

- `index.html` – website content
- `styles.css` – design and responsive layout
- `script.js` – mobile navigation and copyright year
- `assets/oulu-quantum-club-logo.png` – club logo

## Editing

The easiest places to customize later are:
- Winter School details in the `#winter-school` section
- community/contact links in the `#join` section
- activity descriptions in the `#activities` section
